# Customer 360 — Data Analysis Project

## Project Overview

Customer 360 is an end-to-end data analysis project focused on understanding customer behavior, purchasing patterns, app engagement, customer support, and churn.

The project uses Python and Pandas to explore multiple datasets, assess data quality, identify meaningful patterns, and generate business insights that can support data-driven decision-making.

## Project Objectives

- Explore and understand customer-related datasets.
- Assess data quality and identify potential inconsistencies.
- Analyze customer transactions and purchasing behavior.
- Understand app usage and customer engagement.
- Explore customer support interactions and satisfaction.
- Investigate customer churn patterns.
- Generate actionable business insights and recommendations.

## Datasets

The project includes five datasets:

| Dataset | Description |
|---|---|
| `customers.csv` | Customer demographic and profile information |
| `transactions.csv` | Customer transaction records |
| `app_usage.csv` | Customer application usage and engagement |
| `churn.csv` | Customer churn status and related information |
| `support_tickets.csv` | Customer support tickets and satisfaction |

## Project Workflow

1. **Data Exploration & Profiling** — Understanding dataset structures, distributions, and relationships.
2. **Data Quality Assessment** — Identifying missing values, duplicates, inconsistencies, and potential data issues.
3. **Data Analysis** — Investigating business questions and customer behavior.
4. **Data Visualization** — Communicating findings through charts and visual analysis.
5. **Business Insights & Recommendations** — Translating analytical findings into meaningful recommendations.
